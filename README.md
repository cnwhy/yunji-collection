# 云笈收藏助手

把当前网页一键收藏到[云笈](https://github.com/cnwhy/yunji)导航站的浏览器扩展。

## 功能

- **一键绑定 / 解绑**：配置云笈站点地址（或在云笈站点页面自动识别后一键绑定），支持多地址分别保存空间凭证
- **多空间管理**：空间ID + 密码登录、同步浏览器当前登录会话、过期内联重新登录、删除凭证
- **一键添加**：直接用默认「浏览器收藏」分类 + 第一个环境收藏当前页，不弹表单
- **自定义添加**：可修改名称、网址，并选择收藏到哪个分类和环境
- **任意协议页面**：支持收藏 `chrome://`、`file://`、`about:` 等内部地址
- **跨域开关**：在云笈站点上放开跨域限制，便于浏览器端正常获取站点图标

## 下载

在 [Releases](https://github.com/cnwhy/yunji-collection/releases) 页面下载最新版：

- `yunji-collection-0.1.0-chrome.zip`：常规安装（推荐）
- `yunji-collection-0.1.0-chrome.crx`：企业/内部部署

## 安装（zip，推荐）

1. 下载 zip 并解压到一个固定文件夹（解压后里面有 `manifest.json`）
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
3. 打开右上角「开发者模式」开关
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹
5. 在工具栏固定扩展图标即可使用

> 也可以直接把 zip 文件拖拽到 `chrome://extensions` 页面安装。
> 非商店安装的扩展，Chrome 会显示「开发者模式扩展」提示，属正常现象。

## 企业部署（crx）

crx 未由 Chrome 网上应用店签名，普通用户直接拖拽会被 Chrome 拦截（提示「只能从网上应用店添加扩展」）。企业/内部环境请通过组策略安装：`ExtensionInstallForcelist` 配置项指向 crx 文件地址与更新地址。

## 使用

1. **绑定云笈**：打开扩展 → 填写云笈地址（或直接打开云笈站点，扩展会自动识别并显示「绑定云笈」按钮）→ 绑定
2. **添加空间**：绑定后点击「＋ 添加空间」输入空间ID和密码，或点击「⇄ 同步浏览器登录」直接复用当前浏览器登录的云笈会话
3. **收藏网页**：在任意网页上打开扩展，点击「一键添加」立即收藏；或点「收藏到云笈」修改名称/网址、选择分类和环境后确认
4. **跨域开关**：云笈站点页面上点击「点击放开跨域」，放开后浏览器端才能正常获取各站点图标
5. **解绑**：点击标题旁的 ✕ 清除绑定、当前地址下的空间凭证及该地址的跨域放行

## 开发构建

```bash
npm install
npm run build   # 产物在 .output/chrome-mv3/
npm run zip     # 生成 zip
```

> `.output/yunji-collection-key.pem` 是 crx 签名私钥，务必妥善保存：后续版本必须用同一私钥重新打包 crx，否则已安装用户无法覆盖升级，只能卸载重装。

## 隐私

数据（云笈地址、空间凭证）仅保存在本地浏览器存储；密码仅用于登录换取凭证，不落盘。详情见 [PRIVACY.md](PRIVACY.md)。
